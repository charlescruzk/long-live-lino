# The sky (archived)

The first web version: an endless, drifting WebGL sky of photos. Visitors could click the sky to
leave a "light" for Lino (a star with an optional message), stored in a free Supabase project.

It was retired in November 2026 for the ceremony slideshow, once the notes were no longer wanted.
The Supabase project paused for inactivity, as free-plan projects do after about a week without use.

- The last working version is tagged `sky-final` (`git checkout sky-final` to see it as it was, photos included).
- `index.html`, `web.py`, `lights-config.js` and `supabase/setup.sql` are the files it ran on.
- `lights-export.json` / `lights.md` (when present) hold the lights people left, saved before the project was let go.
